|---|---|

## E2E는 왜 여기서 안 도나

Playwright 검사는 로컬 Supabase(도커)와 촬영용 가짜 카메라가 필요하다.
맥에서 `npm run e2e`로 돌린다. 올리기 전에 한 번 돌리는 것을 기준으로 한다.

## iOS — 지금 되는 것과 안 되는 것

**되는 것**: 맥 러너에서 시뮬레이터용으로 빌드해 본다. 인증서가 없어도 된다.
플러그인을 추가하거나 `capacitor.config.ts`를 고쳤을 때 iOS가 깨졌는지 바로 안다.

**안 되는 것**: 폰에 설치할 파일(.ipa) 만들기.

Ad Hoc이든 TestFlight든 **유료 애플 개발자 계정(연 $99)** 이 있어야 인증서와 프로파일이 나온다.
2026-09-21 기준 계정이 없어서 iOS 자동 빌드는 만들지 않았다.

그동안 아이폰은 이렇게 쓴다.

- 맥에서 `scripts/app-dev.sh live-ios` — 앱이 배포된 웹 주소를 불러온다. 배포하면 앱 내용도 같이 바뀐다
- 무료 서명이라 **7일마다** 맥에 연결해 다시 설치해야 한다

계정을 사면 그때 필요한 것: 폰 UDID 등록, 인증서 `.p12`(+비밀번호), Ad Hoc 프로파일, Team ID `36343444V7`.
GitHub Secrets에 `IOS_P12_BASE64`, `IOS_P12_PASSWORD`, `IOS_PROFILE_BASE64`, `IOS_TEAM_ID`로 넣는다.
