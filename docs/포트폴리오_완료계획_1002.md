## 실기기 QA 기록 양식

실제 수행 결과는 [실기기 QA 기록표](실기기_QA_기록_1002.md)에 기입한다. 현재 모든 결과는 미실행/미확인으로 시작한다.

`날짜 / 검사자 / 커밋·배포 URL·APK / 기종·OS / 브라우저 또는 앱 / 시나리오 / PASS·FAIL·미실행 / 증거 / 이슈`

최소 시나리오: 인증·재로그인, 촬영 권한 거부 후 복구, 연속 촬영과 줌, 사진·영상·혼합 편물, 3분할 위치 조정, 영상 생성, 사진첩 저장 후 재생, 공개 범위와 결과물 숨김, 삭제·복원.

촬영 지연은 같은 폰·환경·사진 조건에서 여러 번 측정한다. 실제 비교 결과가 없으면 “성능 N% 개선” 같은 수치를 쓰지 않는다.

## 완료 판정

- 데모에 포함할 핵심 흐름을 최신 후보로 끝까지 수행했다.
- 데이터 유실·권한 노출·가입/촬영/저장 차단 같은 핵심 결함이 남아 있지 않다.
- 변경 후 필요한 자동 검사와 영향받은 실기기 재검증을 마쳤다.
- 배포 URL, 실행 방법, 알려진 한계, 데모 자료가 준비됐다.
- 하은·다희·AI의 기여를 구분하고 직접 설명할 수 있다.

운영 인증이나 실기기 검증이 미완료이면 “전체 공개 완료”로 쓰지 않는다. 포트폴리오 초안은 작성하되 해당 상태와 범위를 명시하고 검증을 이어간다.
