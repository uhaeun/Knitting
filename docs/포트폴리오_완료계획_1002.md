# 포트폴리오 남은 작업

기존 10월 2일 마감 계획에서 남겨 둔 확인 목록입니다. 새 일정이나 완료 사실을 뜻하지 않습니다. 구현 버전과 실행 결과는 [검증 기록](MVP_상태.md)을 기준으로 봅니다.

1. 운영 인증 메일 수신과 복귀, iPhone·Android 핵심 흐름을 확인하고 [실기기 기록](실기기_QA_기록_1002.md)에 남깁니다.
2. 촬영 지연 제보를 같은 기기·조건에서 다시 확인합니다. 비교 측정 없이 개선율을 쓰지 않습니다.
3. 최신 후보에서 공개 범위·차단·숨김·삭제·복원을 확인합니다.
4. 실제 화면과 데모를 준비하고, 하은·다희·AI가 맡은 일을 [초안](포트폴리오_초안.md)에 구분합니다.
5. 약관·개인정보 내용과 시험 데이터의 소유자·정리 범위를 확인합니다.

새 기능 추가나 테스트 개수 확대보다 위 항목을 먼저 마칩니다. 스토어 심사 완료를 포트폴리오 제출 조건으로 확정한 기록은 없습니다.
