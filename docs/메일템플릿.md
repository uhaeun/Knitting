2026-09-20 작성 · 붙여 넣는 곳: Supabase 대시보드 → Authentication → Emails → Templates

## 3. 발송 서버 직접 연결 (10/2 전 필수)

기본 발신 서버는 **시간당 2통** 제한이고 공용이라 네이버 등에서 차단될 수 있다.

1. resend.com 가입 (무료: 월 3,000통, 하루 100통)
2. API Keys → Create API Key
3. Supabase 대시보드 → Project Settings → Authentication → SMTP Settings → Enable Custom SMTP
   - Host `smtp.resend.com`
   - Port `465`
   - Username `resend`
   - Password: 발급받은 API 키
   - Sender email: 도메인을 연결하지 않았다면 `onboarding@resend.dev`
   - Sender name: `닛팅`
4. 저장한 뒤 가입을 한 번 해 보고 메일이 오는지 확인

도메인(`knitting.app` 같은)을 사면 `hello@도메인`으로 보낼 수 있고 스팸함에 덜 들어간다.
