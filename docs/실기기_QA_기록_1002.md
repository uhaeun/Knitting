## 현재 연결·운영 설정 확인

- 이 맥에서 확인한 iPhone은 페어링돼 있으나 연결 터널이 끊겨 있었다. Android 연결 기기는 없었다. 실기기 실행 완료를 뜻하지 않는다.
- 운영 Auth 공개 설정의 읽기 전용 조회: `external.email=true`, `disable_signup=false`, `mailer_autoconfirm=false`. 이메일 가입·확인 요구가 켜져 있음을 확인했다.
- 위 조회는 SMTP 연결·실제 발송·수신·복귀 URL의 성공을 증명하지 않는다. 테스트 메일을 보내지는 않았다.
