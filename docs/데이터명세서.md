# 닛팅 데이터 명세서

2026-09-18 기준 · Supabase(PostgreSQL) · 마이그레이션 `0001`~`0005`

## 표 관계

```
auth.users ─1:1─ profiles ─1:N─ projects ─1:N─ posts ─1:N─ comments
                    │                            └─1:N─ reactions
                    ├─N:M─ follows (follower/followee)
                    ├─N:M─ blocks  (blocker/blocked)
                    └─1:N─ reports (post | comment | profile)
```

## profiles

| 컬럼 | 형 | 제약 |
|---|---|---|
| id | uuid | PK, `auth.users` 참조, 계정 삭제 시 함께 삭제 |
| username | text | 필수, 중복 불가, `^[a-z0-9_]{3,20}$` |
| display_name | text | 필수, 1~30자 |
| bio | text | 150자 이하 (**입력 화면 없음**) |
| avatar_path | text | (**입력 화면 없음**) |
| is_private | bool | 기본 false |
| eula_version | int | 기본 0 |
| created_at / updated_at / deleted_at | timestamptz | deleted_at은 소프트 삭제 |

## projects

| 컬럼 | 형 | 제약 |
|---|---|---|
| id | uuid | PK |
| owner_id | uuid | 필수, profiles 참조 |
| name | text | 필수, 1~50자 |
| cover_post_id | uuid | posts 참조, 기록이 지워지면 null |
| started_at | date | 기본 오늘 |
| finished_at | date | (**쓰는 화면 없음**) |
| default_visibility | enum | private / followers / public, 기본 private |
| reminder_enabled / reminder_time | bool / time | (**쓰는 화면 없음**) |
| deleted_at | timestamptz | 소프트 삭제 |

## posts (사진·영상 기록)

| 컬럼 | 형 | 제약 |
|---|---|---|
| id | uuid | PK |
| project_id / owner_id | uuid | 필수 |
| photo_path | text | 필수. 영상 기록도 **첫 장면 대표 사진**을 넣는다 |
| thumb_path | text | 필수 (400px) |
| width / height | int | 필수 |
| media_type | text | `photo`(기본) / `video` — 0005 |
| video_path | text | 영상이면 필수, 사진이면 null — 0005 |
| duration_ms | int | 영상이면 **1~5500**, 사진이면 null — 0005 |
| caption | text | 500자 이하 (**입력 화면 없음**) |
| taken_at | timestamptz | 필수 |
| visibility | enum | 기록별 공개 범위 |
| like_count / comment_count | int | **서버 트리거가 센다** |
| hidden_at | timestamptz | 신고 3회면 자동으로 채워진다 |
| deleted_at | timestamptz | 소프트 삭제 |

제약 이름 `posts_video_fields`: 사진이면 video_path·duration_ms가 모두 없어야 하고, 영상이면 둘 다 있어야 한다.

## 그 밖의 표

| 표 | 키 | 내용 |
|---|---|---|
| follows | (follower_id, followee_id) | status `pending`/`accepted`. **서버 트리거가 정한다** — 상대가 비공개면 pending |
| blocks | (blocker_id, blocked_id) | 넣으면 트리거가 양방향 팔로우를 지운다 |
| comments | id | body 1~300자, hidden_at, deleted_at |
| reactions | (post_id, user_id) | kind `like`/`cheer` — **cheer는 쓰지 않는다** |
| reports | id | target_type `post`/`comment`/`profile`, status `open`/`actioned`/`dismissed`. 같은 대상 중복 신고 불가 |

## 저장소 (Storage)

| 항목 | 값 |
|---|---|
| 버킷 | `photos` (비공개) |
| 경로 | `{계정}/{편물}/{기록}.jpg`, `_t.jpg`(썸네일), `.mp4` |
| 허용 형식 | `image/jpeg`, `video/mp4` |
| 한 파일 최대 | 10MB |
| 읽기 | 서명 주소 1시간, 15분 남으면 갱신 |

## 권한 규칙 (RLS) 요약

| 표 | 읽기 | 쓰기 |
|---|---|---|
| profiles | 본인 / 공개 계정 / 승인된 팔로워. 차단 사이는 제외 | 본인만 |
| projects | 본인 전부. 남은 "보이는 기록이 하나라도 있을 때" | 본인만 |
| posts | 본인 전부(삭제·숨김 포함). 남은 삭제·숨김이 아니고 공개 범위를 만족할 때 | 본인 + 자기 편물에만 |
| comments | 그 기록이 보일 때 | 작성자. 삭제는 작성자 또는 기록 주인 |
| reactions | 기록이 보일 때 | 본인 것만 |
| reports | 본인 신고만 | 본인만 넣기 (처리 상태는 관리자만) |
| storage | 내 폴더 또는 **보이는 기록이 그 경로를 쓰고 그 기록 주인이 폴더 주인일 때** | 내 폴더만 |

마지막 줄이 0005에서 막은 구멍이다. 남의 파일 경로를 내 공개 기록에 적어도 열리지 않는다.

## 서버 함수 (RPC)

| 함수 | 하는 일 |
|---|---|
| `project_summaries()` | 편물 목록 + 사진 수 + 표지를 한 번에 |
| `set_project_visibility(pid, v)` | 편물과 **그 편물의 모든 기록** 공개 범위를 함께 바꾼다 |
| `soft_delete_project(pid)` | 기록과 편물에 deleted_at을 찍는다. 파일은 남긴다 |
| `feed_*` 계열 | 피드·탐색 목록 |

## 트리거

| 트리거 | 동작 |
|---|---|
| `set_follow_status` | 비공개 계정을 팔로우하면 pending |
| `unfollow_on_block` | 차단하면 양방향 팔로우 삭제 |
| `auto_hide_on_reports` | 신고 3건이면 hidden_at |
| `bump_like_count` / `bump_comment_count` | 좋아요·댓글 수 유지 (댓글을 지우면 줄어든다) |

## 서버 함수

| 이름 | 마이그레이션 | 하는 일 |
|---|---|---|
| `project_summaries()` | 0004 | 편물 목록 (기록 수·표지) |
| `set_project_visibility(pid, v)` | 0004 | 편물과 그 기록의 공개 범위를 한 트랜잭션으로 |
| `soft_delete_project(pid)` | 0004 | 편물과 기록 소프트 삭제 |
| `delete_my_account()` | 0006 | 로그인한 본인의 `auth.users` 삭제. profiles·projects·posts·comments·reactions·follows·blocks·reports가 cascade로 함께 사라진다. Storage 파일은 앱이 먼저 지운다 |

## Storage 버킷

| 버킷 | 공개 | 크기 | 형식 | 경로 |
|---|---|---|---|---|
| photos | 비공개 (서명 URL 1시간) | 5MB | image/jpeg, video/mp4 | `{owner}/{project}/{post}.jpg` · `_t.jpg` · `.mp4` |
| avatars | **공개** | 2MB | image/jpeg | `{user}/avatar-{시각}.jpg` (마이그레이션 0007) |

프로필 사진은 피드·탐색에서 남의 것도 보여야 해서 공개 버킷이다. 서명 URL을 사람 수만큼 발급하면 목록 한 번에 요청이 수십 개가 된다.
