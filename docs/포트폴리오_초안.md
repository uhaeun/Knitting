# 닛팅 포트폴리오 초안

같은 구도로 찍은 뜨개 사진과 영상으로 비교 사진·성장 영상을 만드는 팀 프로젝트입니다. 서비스와 실행 방법은 [README](../README.md), 실행 결과와 미확인 항목은 [검증 기록](MVP_상태.md)에 있습니다.

## 담을 사례

**촬영 지연:** Android에서 촬영 반응이 느리고 여러 번 눌러야 한다는 제보가 있었습니다. 다희의 [PR #20](https://github.com/uhaeun/Knitting/pull/20)에서 이미지 처리와 줌을 변경했습니다. 당시 변경과 제보는 [이슈 #14](https://github.com/uhaeun/Knitting/issues/14)에 있습니다. 동일 기기의 전후 측정이 없어 개선율은 쓰지 않습니다.

**공개 권한:** 결과물 발행을 통합하면서 DB 정책이 서로를 참조해 사진 조회가 실패했습니다. 상태 확인 함수를 분리하고 공개 범위·차단·삭제·복원을 검사했습니다. [통합 PR #25](https://github.com/uhaeun/Knitting/pull/25)와 [SQL 검사](../supabase/tests/rls_matrix.sql)가 근거입니다.

두 사례는 팀 작업입니다. 다희의 PR #20~24와 하은의 기여를 구분하고, AI가 작성한 코드·검사·문서와 사람이 결정하고 확인한 내용을 따로 적어야 합니다. 하은의 세부 개인 기여는 기존 초안에서도 미확정이므로 추정해 채우지 않았습니다.

## 제출 전에 채울 것

- 하은이 직접 결정·검토·수행한 일과 해당 이슈·PR·실행 자료
- 최신 후보의 실기기 결과와 남은 한계
- 실제 화면 4~6장, 촬영부터 결과물 저장·공유까지 보여주는 60~90초 데모

사용 기간·사용자 수·성능 수치는 근거가 있을 때만 기재합니다.
