# 닛팅 — 포트폴리오 초안

2026-09-29. 팀 프로젝트 설명 초안이며 개인 기여는 사용자 확인 후 작성한다.

## 한 줄 소개

뜨개 편물의 변화를 같은 구도로 기록하고, 쌓인 사진·영상을 성장 영상과 비교 사진으로 만드는 서비스.

## 문제와 핵심 경험

편물이 자라는 과정을 비교하려면 촬영 구도와 기록 순서를 맞추고 여러 장을 다시 편집해야 한다. 닛팅은 이전 사진을 참고하는 촬영부터 기록 관리, 전후·3분할 사진과 성장 영상 생성, 결과물 공유까지 한 흐름으로 연결한다.

## 구현과 배포

- Expo 57·React Native Web·TypeScript로 공통 화면을 구현했다.
- Supabase 인증·DB·Storage를 사용하고 RLS로 데이터 접근을 제한한다.
- 사진 합성과 Mediabunny 기반 영상 생성을 제공한다.
- Vercel에 웹을 배포했고, Capacitor 기반 iOS·Android 프로젝트를 유지한다. Android APK 자동 빌드가 있다.
- [배포 웹](https://knitting-pied.vercel.app) / [저장소](https://github.com/uhaeun/Knitting). 9/29 기준 공개 저장소임을 확인했다.

## 설명할 만한 팀 문제 해결 사례

### 촬영 지연

- 관찰: Android에서 촬영 반응이 느리고 여러 번 눌러야 한다는 제보가 있었다.
- 변경: 원본 카메라 해상도로 인코딩하던 캔버스의 최대 변을 2560px로 제한하고 줌 변경과 함께 통합했다.
- 근거: [이슈 #14](https://github.com/uhaeun/Knitting/issues/14), [다희님 PR #20](https://github.com/uhaeun/Knitting/pull/20).
- 남은 증거: 동일 기기에서의 반응 시간·화질 비교. 현재 정량적 개선율은 미측정이다.

### 결과물 공개 권한과 정책 순환

- 문제: 결과물 발행 기능을 통합하면서 DB 정책이 posts → projects → posts를 참조해 사진 조회가 실패하는 것을 재현했다.
- 해결: 상태 확인 함수를 분리하고 각 행의 공개 범위·소유권·차단 판단을 유지했다. 편물 비공개 전환과 삭제가 기존 결과물 접근에도 반영되도록 수정했다.
- 검증: DB 권한 45개 검사에 비공개·차단·삭제·복원 및 결과물 발행 거부 사례를 포함했다. [통합 PR #25](https://github.com/uhaeun/Knitting/pull/25).
- 설명할 점: 왜 함수 분리가 순환을 끊는지, 함수 권한과 행 접근 정책을 어떻게 제한했는지 직접 설명한다.

### 웹과 앱의 검증 범위 분리

- 웹의 사용자 흐름은 Playwright, DB 접근 제어는 SQL, 앱의 OS 권한·사진첩·알림은 Appium 및 실기기로 나눴다.
- 출시 코드 `d43894d`에서 단위 135개·권한 45개·E2E 30개와 Android APK·iOS 시뮬레이터 빌드가 통과했다. [검사 기록](https://github.com/uhaeun/Knitting/actions/runs/36575873070).
- Android 16 에뮬레이터에서 카메라 권한 유지·갤러리 저장·알림 도착 3개를 확인했다. [실행 기록](Android_에뮬레이터_QA_20260929.md).
- iPhone 16 Pro / iOS 27.0에 배포 웹 연결 앱을 설치하고 실행했다. 화면 표시·촬영·저장 등 기능 QA는 아직 사용자 확인 대기다.
- 자동 검사 통과와 실기기 통과를 분리해 기록한다. 테스트 개수만으로 품질이나 전체 기능의 검증 완료를 주장하지 않는다.

## 데모 구성 — 60~90초

1. 편물 목록에서 실제 데모 편물 선택.
2. 이전 사진을 참고해 촬영하고 기록이 추가되는 모습.
3. 전후·3분할 비교와 위치 조정.
4. 성장 영상 생성과 전환 옵션.
5. 결과물을 저장하고 실제 파일 열기.
6. 발행한 결과물이 다른 계정의 피드에 표시되는 모습.

촬영할 화면 4~6장: 편물 목록, 촬영, 기록 상세, 3분할 결과물, 성장 영상, 결과물 피드. 개인정보나 인증 정보가 보이지 않는 데모 데이터를 사용한다.
