## 플랫폼과 구현

Expo 57·React Native Web 화면을 Vercel 웹과 Capacitor iOS·Android 앱에서 공유한다. 9/17 웹 전환 이후 하이브리드 앱이 추가됐다. 앱스토어 배포는 완료되지 않았다.

Supabase(Auth·PostgreSQL RLS·Storage)가 기록의 원본이다. 카메라·영상 처리는 브라우저/WebView API, 앱의 사진첩 저장·로컬 알림은 Capacitor 플러그인을 쓴다.

| 영역 | 구현 |
|---|---|
| 계정 | 이메일 가입·인증 안내, 로그인, 비밀번호 재설정, 프로필·사진 편집, 계정 삭제 |
| 편물 | 이름·시작일·완성일·공개 범위, 사진·영상 기록, 날짜·순서·메모 수정, 휴지통·복원 |
| 촬영 | 이전 사진 겹치기, 격자, 사진 디지털 줌, 최대 5초 영상, 앨범 가져오기 |
| 결과물 | 전체·전후·3분할 사진, 비율·세로 위치, 성장 영상의 유지 시간·컷·페이드 |
| 공유 | 파일/공유 창/앱 사진첩 저장, 결과물 발행, 일상 사진만 타인에게 숨김 |
| 소셜 | 팔로우·승인, 피드·탐색·검색, 좋아요·댓글·소식, 차단·신고 |
