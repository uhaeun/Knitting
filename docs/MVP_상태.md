# 닛팅 MVP 상태 (2026-09-07)

## 되는 것

| 영역 | 내용 |
|---|---|
| 편물 | 만들기(이름·시작일·공개범위), 목록, 삭제, 공개범위 변경 |
| 촬영 | 1:1 고정, 고스트 레이어(끔/30/60), 3×3 격자, 앨범에서 가져오기, 권한 거부 안내 |
| 저장 | EXIF 정규화 → 중앙 정사각 크롭 → 1440 리사이즈 → 400 썸네일 → 파일 → DB |
| 타임라인 | 정사각 사진, 스크러버(처음/마지막), 날짜·카운터 |
| 영상 | 기기 안에서 H.264 MP4 생성, 진행률, 앨범 저장, 공유 |
| 계정 | 이메일 가입·로그인, 온보딩(아이디·표시이름·비공개), 로그인 없이 쓰기 |
| 동기화 | 로컬 우선 push/pull. 기기를 바꿔도 편물과 사진이 따라옴 |
| 피드 | 팔로잉 피드, 탐색(최신/인기), 사용자 검색 |
| 소셜 | 팔로우(비공개는 승인 대기), 요청 승인·거절, 좋아요, 댓글 |
| 안전 | 신고(사유 5종), 차단(양방향), 차단 목록, 신고 3회 자동 숨김 |

## 켜기 전에 사람이 해야 할 것

1. Supabase 프로젝트 생성 → `supabase/migrations/0001_init.sql`을 SQL Editor에 붙여 실행
2. Authentication → Providers → Email → **Confirm email 끄기** (도그푸딩 중)
3. 루트에 `.env` 만들기 (`.env.example` 참고). 넣지 않으면 앱은 로컬 전용으로 동작한다
4. `npx expo run:ios --device` 로 재빌드 (네이티브 모듈이 늘었다)

## 확인한 것 / 확인 못 한 것

- 확인: TypeScript strict 통과, 단위 테스트 20건, iOS/Android 네이티브 컴파일, JS 번들 3.6MB
- **확인 못 함**: 실기기에서의 영상 인코딩 속도·색상, 두 기기 사이 동기화, RLS 조합 10종.
  RLS는 눈으로 검증할 수 없다 — 설계도 4장 검증 매트릭스를 SQL 테스트로 고정할 것

## MVP에 넣지 않은 것

푸시 알림, Apple·Google 로그인, 이미지 자동 검사(Vision API), 결과 사진(2·3분할),
대댓글·DM, 다크 모드, 촬영 리마인더, 계정 삭제 자동화(현재는 메일 요청)
