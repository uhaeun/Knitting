# 닛팅 테스트 안내

받는 사람: 테스트를 도와주는 사람 (2026-09-18 기준)

앱스토어에 올리지 않았다. **웹앱**이라 주소만 열면 된다. 설치 심사도, 테스트 초대도 없다.

## 1. 열기

https://knitting-pied.vercel.app

브라우저에서 바로 써도 되지만, **홈 화면에 추가하면 앱처럼 열린다** (주소창이 사라지고 전체 화면).

**iPhone (Safari)**
1. 위 주소를 Safari로 연다 (크롬 말고 Safari여야 한다)
2. 아래 가운데 공유 버튼 → "홈 화면에 추가"
3. 홈 화면의 **닛팅** 아이콘으로 연다

**Android (Chrome)**
1. 위 주소를 연다
2. 오른쪽 위 ⋮ → "앱 설치" 또는 "홈 화면에 추가"

## 2. 계정 만들기

아무 이메일이나 쓸 수 있다. 실제로 오는 주소가 아니어도 된다 (지금은 이메일 확인을 끄고 있다).

- 예: `test다희@example.com` / 비밀번호 6자 이상
- 아이디는 영문 소문자·숫자·밑줄 3~20자
- **계정을 2개 만들면 좋다.** 서로 팔로우하고 공개 범위를 확인할 수 있다

## 3. 무엇을 보나

[테스트케이스](테스트케이스.md)의 항목을 순서대로 확인한다. 기기별로 나눠 맡는다.

| 누가 | 기기 | 특히 볼 것 |
|---|---|---|
| 하은 | iPhone Safari | 영상 비율, 앨범 영상 회전, 사진첩 저장 |
| 다희 | Android Chrome | 설치 안내, 촬영·녹화(코덱이 다르다), 갤러리 저장, 뒤로 가기 |

30분만 쓸 수 있다면 이 순서로 본다.

1. 편물 만들기 → 사진 3장 찍기
2. 영상 모드로 3초 녹화 → 저장되는지
3. 결과 사진 → 전후·3분할 → 저장 (사진첩에 들어오는지)
4. 영상 만들기 → 저장
5. 탐색에서 상대 계정 찾아 팔로우 → 상대 기록이 보이는지

## 4. 문제를 찾으면

노션 「닛팅」 아래에 결함으로 남긴다. 양식은 [테스트 계획](테스트계획.md) 5절에 있다.

빠르게 남길 때는 이 세 줄만 있어도 된다.

```
무엇을 했나:
기대한 것:
실제로 본 것:  (+ 스크린샷이나 화면 녹화)
```

기기와 OS 버전을 같이 적어 주면 좋다. 예: iPhone 15 / iOS 18.7 / Safari.

## 5. 알아 둘 것

- **지금 넣는 데이터는 실제 서버에 쌓인다.** 10/2 공개 전에 테스트 계정과 사진을 전부 지운다
- 사진·영상은 서버에 저장되고, 공개 범위는 편물마다 정한다. 기본은 "나만"이라 남에게 보이지 않는다
- 아직 없는 기능: 비밀번호 찾기, 프로필 편집, 알림, 계정 삭제. 못 찾아도 정상이다
- 안 되는 걸 발견하면 그게 이 테스트의 목적이다. 편하게 부숴 주면 된다
