### 마일스톤

`10/2 공개` 하나만 쓴다. 여기 없는 이슈는 10/2에 안 한다는 뜻이다.

### 상태

GitHub Projects 대신 **라벨과 담당자**로만 본다. 칸반을 새로 배우는 데 시간을 쓰지 않는다.

- 담당자가 없으면 아무도 안 하고 있는 것이다
- 고친 커밋 메시지에 `#이슈번호`를 적으면 이슈에 자동으로 연결된다
- 배포까지 끝나면 하은이 "배포됨"이라고 댓글을 단다 → **연 사람이 실제 기기에서 확인하고 닫는다**

### 버그를 쓸 때 꼭 넣을 것

양식(`버그`)이 물어보는 대로만 적으면 된다. 특히 **시각**을 적어 주세요.
그 시각으로 Supabase의 `client_errors` 표에서 같은 오류를 찾을 수 있다 ([보는 법](오류보기.md)).

## 4. 자동 검사, 누가 언제 돌리나

### 웹 — Playwright (하은)

```bash
npm run e2e          # 27개 전부, 15~20분
node scripts/e2e/crud.mjs   # 하나만
```

- 로컬 Supabase(도커)가 필요해서 GitHub에서는 못 돌린다. **올리기 전에 맥에서 돈다.**
- GitHub에서 자동으로 도는 것: 타입 검사 + 단위 테스트 118개 (`검사` 워크플로)

### 네이티브 — Appium (다희)

```bash
cd tests/native && source .venv/bin/activate && pytest -v
```

지금 3개가 있다. 카메라 권한, 사진첩 저장, 알림.
**10/2까지 다희가 늘릴 것 3개** (한 번에 하나씩, 이슈로 만들어 두었다)

1. 가입 → 이메일 인증 → 첫 설정까지 앱 안에서
2. 앱에서 계정 삭제 → 다시 로그인 안 됨
3. 여러 장 올리기 → 타임라인에 순서대로 쌓임

APK는 main에 올릴 때마다 자동으로 만들어진다 → [Actions](https://github.com/uhaeun/Knitting/actions)의 `Android APK 빌드` → 맨 아래 Artifacts.

### 손으로 보는 것 (자동으로 못 보는 것)

- 사진·영상이 **예쁘게** 나오는가 (잘림, 회전, 색)
- 느린가 (촬영 후 저장까지, 영상 만들기)
- 글자가 잘리거나 겹치는가
- 알림이 **정한 시각에** 오는가 (하루 걸쳐 봐야 한다)

- 막힌 것(`blocked`)은 누가 풀어야 하는지 한 줄로

## 7. 무엇이 되면 "끝"인가

10/2에 아래가 모두 사실이어야 한다.

1. 모르는 사람이 가입해서 첫 기록을 남길 수 있다 (메일 인증 포함, 메일이 5분 안에 온다)
2. iPhone·Android 실기기에서 촬영 → 결과 사진 → 사진첩 저장이 된다
3. `P0` 이슈가 0개, `P1` 이슈가 0개
4. Playwright 27개와 단위 테스트 118개가 통과한다
5. Appium 검사 6개가 통과한다
6. 테스트로 만든 계정·편물이 실제 서버에 남아 있지 않다
7. 약관·개인정보처리방침을 둘 다 읽고 사실과 맞는지 확인했다
