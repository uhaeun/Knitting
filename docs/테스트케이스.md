# 닛팅 테스트케이스

2026-09-18 기준 · 대상 https://knitting-pied.vercel.app · 주 환경 iPhone Safari

기법 표기: **EP** 동등분할 · **BVA** 경계값 · **ST** 상태전이 · **DT** 결정표 · **E** 예외

화면 ID는 [화면정의서](화면정의서.md), 규칙은 [기능명세서](기능명세서.md)를 따른다.

## 1. 가입·로그인 (SCR-01)

| ID | 기법 | 사전 조건 | 절차 | 기대 결과 |
|---|---|---|---|---|
| TC-A-01 | BVA | 로그아웃 | 비밀번호 5자 입력 | 버튼 꺼짐 |
| TC-A-02 | BVA | 로그아웃 | 비밀번호 6자 입력 | 버튼 켜짐 |
| TC-A-03 | EP | 로그아웃 | `@` 없는 이메일 입력 | 버튼 꺼짐 |
| TC-A-04 | E | 가입된 이메일 있음 | 그 이메일로 가입 시도 | "이미 가입된 이메일이에요. 로그인해 주세요" |
| TC-A-05 | E | 계정 있음 | 비밀번호를 틀리게 입력 | "이메일 또는 비밀번호가 맞지 않아요" |
| TC-A-06 | ST | 가입 성공 직후 | 화면 확인 | 첫 설정 화면으로 이동, 뒤로 가기로 못 빠져나감 |

## 6. 결과 사진 (SCR-09)

기록 종류에 따른 출력 — **결정표**

| 조건 | 사진만 | 영상 포함 |
|---|---|---|
| 출력 형식 | JPEG | MP4 |
| 미리보기 | 정지 화면 | 반복 재생 |
| 저장 안내 | "이미지 저장" | "비디오 저장" |
| 진행 표시 | "만드는 중" | "만드는 중 N%" |

| ID | 기법 | 사전 조건 | 절차 | 기대 결과 |
|---|---|---|---|---|
| TC-F-01 | BVA | 기록 1개 | 결과 사진 열기 | "전체"만 선택 가능 |
| TC-F-02 | BVA | 기록 2개 | 결과 사진 열기 | "전후"까지 가능, 3분할 비활성 |
| TC-F-03 | BVA | 기록 3개 | 결과 사진 열기 | 3분할이 기본으로 열림 |
| TC-F-04 | DT | 사진 3개 | 3분할 저장 | JPEG, 1080×1080 |
| TC-F-05 | DT | 사진 2 + 영상 1 | 3분할 저장 | MP4, 길이 = 그 영상 길이 |
| TC-F-06 | DT | 영상 2개(3초·5초) | 전후 저장 | MP4 5초, 3초 영상은 마지막 장면에서 멈춤 |
| TC-F-07 | ST | MP4 합성 중 | 종류를 바꿈 | 이전 합성이 멈추고 새 종류로 다시 만듦 |
| TC-F-08 | EP | 기록 3개 중 가운데 날짜 확인 | 3분할 저장 | 가운데 칸이 기간의 한가운데 기록 |

## 9. 자동 검사로 이미 덮은 것 (수동 생략 가능)
