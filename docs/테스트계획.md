# 닛팅 테스트 계획 · 결함 관리

2026-09-18 작성 · 대상 https://knitting-pied.vercel.app

## 1. 범위

**본다**
- 영상 기록(촬영·저장·재생·결과물·성장 영상) — 이번 릴리스의 새 기능
- 기존 사진 흐름의 회귀
- 공개 범위와 권한

**보지 않는다**
- [기능명세서](기능명세서.md) 15절의 "만들지 않은 기능"
- 성능 수치 측정(부하·응답 시간). iPhone에서 탭이 죽는지만 본다
- 접근성 전수 점검

## 2. 환경

| 구분 | 값 |
|---|---|
| 주 환경 | iPhone Safari (iOS 18.7 / Safari 26.6.1에서 선행 시험 완료) |
| 부 환경 | macOS Chrome (자동 검사용) |
| 계정 | 최소 2개 (A: 기록 작성, B: 남의 시선 확인) |
| 데이터 | 편물 3개 — 사진만 / 영상만 / 섞임 |

## 3. 시작·종료 기준

**시작 기준**
- 배포가 끝나고 주소가 열린다
- `npx tsc --noEmit`, `npx jest`, E2E 8종이 모두 통과한다 (2026-09-18 통과)

**종료 기준**
- [테스트케이스](테스트케이스.md)의 TC-E·TC-F·TC-G(영상 관련 27건)를 모두 수행했다
- 심각도 **치명·높음** 결함이 0건이다
- 남은 결함은 원인과 다음 조치가 적혀 있다

## 4. 순서 (2~3시간)

1. 계정 A로 가입 → 편물 3개 만들기 (15분)
2. 촬영: 사진·영상, 앨범 가져오기, 경계값(1초·5초) (40분)
3. 보기: 타임라인·상세 재생, 배지 (15분)
4. 결과 사진: 사진만 / 섞임 / 영상만, 사진첩 저장 (30분)
5. 성장 영상: 길이 확인, 클립 재생, 많은 영상으로 60초 상한 (30분)
6. 계정 B로 권한 확인: 공개 범위 바꾸기, 차단, 신고 (20분)

## 5. 결함 리포트 양식

```
[결함 ID] KNIT-YYYYMMDD-NN
제목: (증상 한 줄, 화면 이름 포함)
환경: iPhone 15 / iOS 18.7 / Safari · 배포 2026-09-18
화면: SCR-08 촬영
심각도: 치명 | 높음 | 보통 | 낮음
우선순위: P1 | P2 | P3

재현 절차:
1.
2.
3.

기대 결과:
실제 결과:
재현율: 3/3
첨부: 스크린샷 또는 화면 녹화
비고: (콘솔 오류, 관련 기록 ID)
```

## 6. 심각도 기준

| 심각도 | 기준 | 예 |
|---|---|---|
| 치명 | 데이터가 사라지거나 남의 것이 보인다 | 비공개 기록이 남에게 보임, 저장한 기록이 사라짐 |
| 높음 | 핵심 기능이 막힌다 | 영상 저장 실패, 성장 영상 만들다 탭이 죽음 |
| 보통 | 되지만 결과가 틀리다 | 영상 비율이 찌그러짐, 길이가 안내와 다름 |
| 낮음 | 보기에 어색하다 | 문구 겹침, 배지 위치 |

## 7. 우선순위 기준

| 우선순위 | 기준 |
|---|---|
| P1 | 이번 릴리스에서 고친다 |
| P2 | 다음 작업 묶음에서 고친다 |
| P3 | 기록만 남긴다 |

심각도와 우선순위는 따로 정한다. 낮은 심각도라도 첫 화면에서 모두가 보면 P1이 될 수 있다.

## 8. 이미 아는 한계 (결함으로 올리지 않는다)

- 탐색의 "인기"는 처음 12개까지만
- 촬영 설정(겹치기·격자·모드)이 저장되지 않음
- 영상 만들기를 지원하지 않는 브라우저는 버튼을 누른 뒤에야 안내가 나옴
- 서버 오류 일부가 영어로 보임
- 비공개 계정 프로필이 "없는 사용자예요"로 보임
